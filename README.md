# 💼 Job Tracker — Sneha's Dashboard

Automated job tracker that scrapes opportunities from top tech companies, filters by your location preferences, matches against your skills, and generates tailored LaTeX resumes.

**Live at:** `http://localhost:8080` (local dev server)

## ✨ Features

- 🔍 **Smart Scraping** — Fetches jobs from 30+ companies via Greenhouse, Lever, and Ashby APIs
- 📍 **Location Filtering** — Target specific cities + remote positions
- 💰 **Pay Sorting** — Top jobs sorted by salary (descending), then match score
- 📝 **Auto-Tailoring** — Generates customized LaTeX resumes for high-match jobs
- 📊 **Apple-Style Dashboard** — Premium dark UI to track status, apply, and download resumes
- 📋 **Resume Ready Cards** — Card-based view with download PDF + apply links for ready jobs
- 💾 **Local Persistence** — Status, notes, and dates saved via localStorage
- ⏰ **Automation** — Schedule daily runs with cron/launchd

## 🚀 Quick Start

### 1. Clone & Setup

```bash
git clone https://github.com/vkrishnav/job-tracker-template.git
cd job-tracker-template

# Copy example config
cp config.example.json config.json
```

### 2. Configure

Edit `config.json` with your info:

```json
{
  "name": "Sneha",
  "master_resume": "./Sneha_Resume.pdf",
  "target_locations": ["remote", "san francisco", "mountain view"],
  "skills": {
    "strong": ["python", "javascript", "react"],
    "proficient": ["aws", "docker", "sql"],
    "familiar": ["kubernetes", "go"]
  }
}
```

### 3. Run

```bash
# Scrape jobs and generate resumes
python3 scripts/daily_monitor.py

# Compile LaTeX to PDF (requires MacTeX)
./scripts/compile_pdfs.sh

# Start dashboard
python3 -m http.server 8080
# Open: http://localhost:8080
```

## 💾 Data Storage

The dashboard uses **localStorage** to persist your updates between sessions:

| Data | Storage | Description |
|------|---------|-------------|
| Job listings | `data/jobs.json` | Generated by the scraper |
| Initial statuses | `data/status.json` | Generated by the scraper |
| Your updates | `localStorage` | Status changes, notes, applied dates |

**Key:** `sneha_job_data` stores per-job data:
```json
{
  "job-id": {
    "status": "applied",
    "notes": "Had phone screen, technical round next week",
    "appliedDate": "2026-03-25",
    "lastUpdated": "2026-03-25T10:30:00Z"
  }
}
```

## ⚙️ Configuration

### `config.json` Fields

| Field | Description |
|-------|-------------|
| `name` | Your full name (used in resume filenames) |
| `master_resume` | Path to your resume (supports relative paths) |
| `target_locations` | Cities/regions to include |
| `exclude_locations` | Regions to exclude |
| `min_match_percent` | Minimum match % for tailored resume (default: 70) |
| `top_jobs_count` | Number of top jobs to track daily (default: 15) |
| `skills.strong` | Expert skills (weighted 3x) |
| `skills.proficient` | Proficient skills (weighted 2x) |
| `skills.familiar` | Familiar skills (weighted 1x) |
| `target_roles` | Job titles to match |
| `companies` | Custom company list |

### `.env` Configuration

```
PORT=8080
RESUME_PATH=./Sneha_Resume.pdf
DATA_DIR=./data
MIN_MATCH_PERCENT=70
TOP_JOBS_COUNT=15
```

### Adding Companies

```json
{
  "companies": {
    "company-name": {
      "api": "greenhouse",
      "board": "company-board-id"
    }
  }
}
```

Supported APIs: `greenhouse`, `lever`, `ashby`

## 🖥️ Dashboard

The web dashboard provides:

- **Stats Overview** — Total jobs, resume ready, applied, avg match (with animated counters)
- **Filter Pills** — All, Resume Ready, New, Applied, 80%+ Match
- **Sortable Table** — Click column headers to sort by Company, Role, Salary, Match, Status
- **Resume Ready Cards** — When filtered, shows rich cards with:
  - 📄 **Download Resume PDF** button (tailored or master resume)
  - 🔗 **Apply Now** link to job application page
  - Skills, salary, match score, and notes
- **Status Modal** — Click any status badge to update:
  - Change status (New → Resume Ready → Applied → Interviewing → Offer)
  - Add notes about the application
  - Set applied date
  - All changes saved to localStorage

## 📅 Automation

### macOS (LaunchAgent)

```bash
cp scripts/launchd.plist ~/Library/LaunchAgents/com.jobtracker.daily.plist
# Edit paths, then:
launchctl load ~/Library/LaunchAgents/com.jobtracker.daily.plist
```

### Cron

```bash
0 8 * * * cd /path/to/job-tracker-template && python3 scripts/daily_monitor.py >> logs/cron.log 2>&1
```

| `applied` | Application submitted |
| `interviewing` | In interview process |
| `offer` | Received offer |
| `rejected` | Not selected |
